# 🍔 Yummigo - Food Ordering App

**Yummigo** is a responsive and user-friendly food ordering web application where users can browse restaurants, explore menus, add items to cart, and place orders online. The goal of this app is to simulate the functionality of real-world food delivery platforms like Swiggy or Zomato.

---

## 🧾 Description

This full-stack food delivery platform allows users to:

- Browse a list of restaurants and food items  
- Search and filter cuisines  
- Add items to cart and adjust quantities  
- Proceed to checkout and place orders  
- View order history (planned feature)

Admins can manage food items, restaurants, and order status (if admin panel is implemented).

---

## 🚀 Features

- 🍽️ Restaurant and menu listing  
- 🛒 Cart management (add, remove, update quantity)  
- 📱 Fully responsive layout for mobile & desktop  
- 🔍 Search by food item or restaurant  
- 📦 Checkout and order summary  
- 🔐 Optional: Authentication for users/admins  
- 📊 Clean UI with interactive UX

---

🛠️ Tech Stack
Frontend
React.js: Interactive UI components.
CSS: Styling for a visually appealing user experience.

Backend
Node.js: Backend server.
Express.js: Web framework for routing and API creation.
MongoDB: Database for storing user data, food items, and orders.

Payment Integration
Stripe: Payment gateway for secure transactions(Test Mode).
